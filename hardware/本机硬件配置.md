# 本机硬件配置（小米 13 / fuxi，型号 2211133C）

> 采集于 2026-10-30，运行主线 Linux `7.3.0+ #207`（Ubuntu 26.10）。
> 全部为**只读**采集，未改设备状态。**不同批次的小米 13 配件可能不同**，见[配件供应商差异](配件供应商差异.md)。

## 2. SoC / CPU / GPU

| 项 | 值 |
|---|---|
| SoC | Qualcomm **SM8550-AB**（骁龙 8 Gen 2），4 nm |
| CPU | 8 核，3 个 cpufreq 策略（实测） |
| ├ 大核 | 1× Cortex-X3（`CPU part 0xd4d`），policy7，最高 **2.9568 GHz**，最低 595.2 MHz |
| ├ 中核 | 3× Cortex-A710/A715（`0xd47`），policy3，最高 **2.8032 GHz**，最低 499.2 MHz |
| └ 小核 | 4× Cortex-A510（`0xd46`/`0xd4e`），policy0，最高 **2.016 GHz**，最低 307.2 MHz |
| 调频 | `schedutil`（三个策略），EPSS |
| GPU | **Adreno 740**（`a740`），GMU 在 `3d6a000.gmu`；Mesa freedreno，GL 4.6 |
| GPU 固件 | `qcom/a740_sqe.fw` 等；ZAP 必须用 `/odm/firmware` 的**小米安全签名版**（`/vendor/firmware` 的高通测试签名会被 TZ 拒绝，`-22`） |
| 温控 | 43 个热区，4 个 cooling device（3×CPU + GPU） |

## 11. 自检命令（在 Linux 侧只读运行）

```bash
uname -a
grep -E 'CPU part|CPU implementer' /proc/cpuinfo | sort -u
head -3 /proc/meminfo
cat /sys/block/sda/device/{vendor,model,rev}
cat /sys/class/drm/card0-DSI-1/status /sys/class/drm/card0-DSI-1/modes
dmesg | grep -iE 'st-ftm5|panel|dsi'
for b in /sys/class/power_supply/*; do echo "$b $(cat $b/model_name 2>/dev/null)"; done
ls /sys/bus/spmi/devices/ /sys/bus/soundwire/devices/ /sys/class/remoteproc/
```

在 Android 侧（只读）：`adb shell getprop ro.product.model`、`adb shell cat /proc/cmdline`。
