# 配件供应商差异（小米 13 / fuxi）

小米 13 同一型号在不同批次会混用不同供应商的配件。**同一份镜像不一定适配所有批次**，
下面是从本机实测与厂商 DTB/Android 模块库中整理出的差异点，以及判断方法。

## 1. 触摸 IC：ST FTM5 ↔ Goodix GT9916

| | STMicroelectronics FTM5 | Goodix GT9916 |
|---|---|---|
| 本机 | ✅ **是这台**（`spi0.0`，chip 3640 / fw 0053 / cfg 0042） | — |
| 厂商 DTB 默认 | — | ✅ `qcom,i2c-touch-active = "goodix,gt9916"`，I2C `0x5d` |
| 主线驱动 | 自写 `st-ftm5`（SPI） | 上游 `goodix_berlin` 支持 GT9916 |
| 判断 | `dmesg \| grep st-ftm5` 有输出 | `i2cdetect -y <bus>` 见 `0x5d` |

> 主线 DTS 目前只按 ST FTM5（SPI）适配。如果自己的机器是 GT9916 批次，需要加一个 I2C 触摸节点
> （`goodix,gt9916`，reset/irq GPIO 在厂商 DTB 的 `goodix,reset-gpio` / `goodix,irq-gpio`），
> 驱动用上游 `goodix_berlin`。**面板/触摸是成对装配的**，换批次时两者都要确认。

## 2. 相机模组：传感器相同，模组厂不同

同一颗传感器由不同模组厂封装，EEPROM、对焦马达、OIS 型号随之不同：

| 位置 | 传感器（固定） | 模组厂 / 版本 | EEPROM | 马达 / OIS |
|---|---|---|---|---|
| 主摄 | Sony IMX800 50 MP | SEMCO `semco_imx800_wide` | p24c128f | AK7314 / BU24721 |
| 主摄 | Sony IMX800 50 MP | Sunny `sunny_imx800_wide_ii` | gt24p256f | AK7314 / BU24721 |
| 长焦 | Samsung S5K3K1 10 MP | SEMCO `semco_s5k3k1_tele` | p24c64f | AK7314 / BU24721 |
| 长焦 | Samsung S5K3K1 10 MP | SEMCO `semco_s5k3k1_tele_ii` | p24c64f | AK7314 / BU24618 |
| 超广角 | OmniVision OV13B10 12 MP | O-Film `ofilm_ov13b10_ultra` | GT24P64E | — |
| 前摄 | OmniVision OV32C 32 MP | Sunny `sunny_ov32c_front` | GT24P64E | — |

- 传感器 **ID 与 I2C 地址**在模组版之间通常相同，但**上电时序、EEPROM 内容、OIS/马达驱动**不同；
  移植时要按实际模组选择对应配置，不能只按传感器型号套用。
- 判断方法（Android 侧只读）：`ls /vendor/lib64/camera/*sensormodule*`，
  文件名即模组厂+传感器+版本，例如 `com.qti.sensormodule.fuxi_semco_imx800_wide.bin`。
  主线侧用 `scripts/fuxi-camera-probe.sh` 逐个上电读 ID 互相印证。

## 3. 显示面板

- 本机为 **Samsung Display**（面板名含 `sec`，ID `M3 38 0c 0a`，1080×2400 DSC 命令模式）。
- 判断方法：
  - Android：`adb shell cat /proc/cmdline | tr ' ' '\n' | grep dsi_display0`，
    得到 `qcom,mdss_dsi_<面板名>_dsc_cmd`；
  - Linux：`dmesg | grep -i panel` + `/sys/class/drm/card0-DSI-1/modes`；
  - 厂商 DTB：`mi,panel-id` 与 `qcom,mdss-dsi-panel-name`。
- 若面板厂商或面板 ID 不同，屏参（上下电序列、DSC 参数、亮度曲线、复位 GPIO）必须重新取，
  不能直接套用本机 `panel-xiaomi-fuxi` 的参数。

## 4. 电池

- 本机：`M3_4500mah_67w`，4500 mAh，Li-poly。
- 判断：`cat /sys/class/power_supply/qcom-battmgr-bat/model_name`。
- 不同容量/充电功率的电芯会影响充电曲线与电流校准，标定前先确认型号。

## 5. 内存 / 存储容量

小米 13 有 8 GB / 12 GB 内存、128 / 256 / 512 GB 存储的组合。

- 内存：`head -1 /proc/meminfo`（本机 12 GB → `MemTotal ≈ 11.15 GB`）
- 存储：`cat /sys/block/sda/device/model`（本机 Samsung `KLUFG8RHHD-B0G1` = 512 GB）
- 容量不同**不影响**内核镜像，但影响分区布局与 `sda33` rootfs 位置假设，刷机前务必核对 GPT。

## 6. 无线/音频/电源（目前未见批次差异）

| 部件 | 型号 | 备注 |
|---|---|---|
| WiFi/蓝牙 | WCN7850 | 各批次一致；差异在**标定数据**（小米标定 vs 上游参考板） |
| 音频 | WCD9385 + 2× CS35L41 | 各批次一致 |
| PMIC | PM8550 / PM8550B / PM8550VE / PM8550VS / PM8010 / PMK8350 | 平台固定 |
| 指纹 | Goodix 屏下光学 | 各批次一致，均走 TrustZone |

## 7. 刷机前自检流程（推荐）

1. Android 侧：`getprop ro.product.model`、`cat /proc/cmdline`（看 `dsi_display0`、`hwid.*`）
2. `ls /vendor/lib64/camera/*sensormodule*`（记录相机模组厂）
3. 进 Linux 后：`dmesg | grep -E 'st-ftm5|panel|ath12k'`、`cat /sys/class/power_supply/qcom-battmgr-bat/model_name`
4. 把结果对照本文；不一致时先改 DTS/驱动，再刷 `recovery_b`
