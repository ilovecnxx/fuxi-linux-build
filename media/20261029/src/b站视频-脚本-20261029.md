### 02 方案选择：两条死路，一条活路（1:10–2:20）

| 画面 | 解说 |
|---|---|
| 旧实验截图/白板图：EDK2 logo、黑屏 | 为什么不用现成方案？先说走过的弯路。第一条是自制 UEFI 固件。EDK2 能跑起来，能拿到 GOP 帧缓冲，但每次把控制权交给主线内核都失败：黑屏、挂起，或者干脆复位。 |
| kexec 命令行一闪而过 | 第二条是 kexec，先起一个最小 Linux，再 kexec 到正式内核，同样不稳定。 |
| 启动链动画：ABL → recovery_b → 内核 | 最后选的方案很朴素：让高通自己的 ABL 直接把 recovery_b 里的镜像拉起来。 |
| 双系统切换实拍（回安卓 / 进 Linux） | 好处是双系统天然成立：正常开机根本不看 recovery_b，随时能回安卓；代价是要绕过 ABL 的一个坑，这个坑后面单独讲。 |

### 03 启动链拆解（2:20–3:30）

| 画面 | 解说 |
|---|---|
| 启动链示意图逐段点亮（XBL → 高通 UEFI → ABL → boot.img v1 → 内核 → initramfs → systemd） | 完整启动链是：XBL、高通 UEFI、ABL，然后是我们自己打的 boot.img。 |
| boot.img 结构图：kernel 字段 = Image.gz + 厂商 DTB，ramdisk 空 | 镜像的 kernel 字段里放的是压缩内核加一个厂商 DTB，ramdisk 为空，initramfs 直接编进内核。 |
| 设备树 chosen/bootargs 高亮 | 内核启动时开着 CONFIG_FUXI_FORCE_BUILTIN_DTB，忽略 ABL 传进来的 DTB，用自己的设备树，连命令行都从设备树里读。 |
| initramfs 串口画面 / 8 秒倒计时 | 接着是 initramfs：等 USB 串口就绪，给 8 秒调试窗口，然后 switch_root 到 sda33 上的 Ubuntu。 |
| **重点图示**：ABL 把 dtbo overlay 叠到 DTB 上 → 黑屏（打红叉） / 厂商 DTB 当诱饵 → 正常（打绿勾） | 坑在哪？ABL 会把 dtbo 分区的 overlay 叠到镜像附带的 DTB 上。叠到主线 DTB 上，百分之百卡死；叠到厂商 DTB 上，一切正常。所以镜像里放厂商 DTB 当诱饵，内核再把它换成自己的——土办法，但是有效。 |

### 04 硬件逐个点亮（3:30–5:40）

| 画面 | 解说 |
|---|---|
| 触摸：手指在桌面滑动的特写 | 触摸：给 ST FTM5 新写的主线驱动。第一次 probe 一直报 -110，控制器没就绪，查下来是上电时序不对；电源稳之前读 chip id 全是 0。 |
| 显示：面板点亮 + 120Hz 设置 | 显示：面板是三星的 DSC 面板，三档刷新率的上电序列只差三条命令。这部分做完，屏幕上才第一次出现真正的桌面，而不是 16×32 的点阵字。 |
| GPU：终端里 `-22` 报错 → 换 `/odm/firmware` 后成功 | GPU：Adreno 740 上电要做 ZAP 签名认证。一开始用 vendor 分区的 zap，TrustZone 直接返回 -22。后来换成 odm 分区里小米签名的那份，一次过。同一颗芯片、两个目录、两套签名，就这一个差别。 |
| 音频：功放 i2c 引脚图（GPIO0/1）→ 左右声道测试音 | 音频：两颗 CS35L41 功放加 WCD938x。坑在 i2c 引脚——本机走 GPIO0 和 GPIO1，不是设备树默认的 56/57，因为 57 是长焦供电。改完才出声。 |
| Wi-Fi：`ath12k` 加载日志 + 已连接 | Wi-Fi：WCN7850，固件从手机自己的 modem 分区里只读拉出来，打包成 board-2.bin。注意不能在 initramfs 阶段 probe，必须等根文件系统就绪再启动 ADSP。 |
| 蓝牙：`btmgmt` 设地址 | 蓝牙：控制器没有出厂地址，得从安卓那边读出本机地址，用 btmgmt 写一次，时序还得等固件下载完。 |
| 传感器：SensorProxy 读数 | 传感器：FastRPC 通上以后，加速度、光线、距离、磁场都有读数了。 |

### 05 系统层的坑（5:40–6:40）

| 画面 | 解说 |
|---|---|
| 锁屏输密码 → 提示认证失败 | 第一个坑很阴：根文件系统打包时 setuid 位丢了。于是锁屏密码明明是对的，却一直提示认证失败——因为 unix_chkpwd 读不到 shadow。 |
| 黑屏/卡死演示（或旧日志截图） | 第二个坑：命令行里千万别加 console=ttyGS0。主机会变成 USB 串口当控制台，主机不读的时候写满阻塞，开关机都能卡死几十秒。 |
| UFS 关机 → 掉进 EDL | 第三个坑：主线 UFS 驱动在关机路径里没放复位线，手机直接掉进 EDL 模式。加一个 shutdown 回调释放复位线才正常。 |
| `cpuidle.off=1` 高亮 | 第四个：早期的排障参数 cpuidle.off=1 一直留在命令行里，于是不进深度空闲、不能挂起、耗电偏高。这一版才把它摘掉。 |

### 06 现在能干什么、不能干什么（6:40–7:20）
