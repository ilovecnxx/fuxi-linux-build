## 二、正文（纯文本，可直接复制）

【先说结论】

我用一台小米 13（fuxi / 骁龙 8 Gen 2）做了个「安卓 + 纯主线 Linux」双系统。

不开玩笑，真的是纯主线内核：Linux 7.3.0，源码直接拿 kernel.org 的，没碰高通厂商内核、没有 Halium、没有 Droidian、没有 Android HAL。

现在这台机器的状态：
· 正常开机 → 进 LineageOS，该打电话打电话
· 关机后「音量上 + 电源」→ 进 Ubuntu 26.10 桌面（Phosh）
· 桌面、触摸、120Hz、GPU 加速、双扬声器、Wi-Fi、蓝牙、中文输入法、浏览器、文件管理器，全部可用
· 玩够了在 Linux 里 reboot，就回安卓，安卓那边一个字节都没动过

【它现在能干什么】

· 显示：原生 MSM DSI 驱动，1080×2400，60/90/120Hz 可切。不是那种「能出个文本控制台」的水平，是真的出桌面
· GPU：Adreno 740 起来了，Phosh 走 GPU 渲染，滑动和动画明显比软件渲染顺
· 触摸：给 ST FTM5 触摸屏新写的主线驱动，触控位置准确
· 声音：两颗 CS35L41 功放 + WCD938x 编解码都通了，左右声道能分开响
· 网络：Wi-Fi 7 网卡（WCN7850 / ath12k）能连、能上网、能刷 HTTPS、能用 Wi-Fi SSH 进手机；蓝牙也能连对端
· 输入：屏幕键盘 + 拼音中文输入，能打中文、能存文件
· 电源：能读电量、充电状态、温度；CPU 调频和温控（43 个热区、3 个 cooling 设备）都在跑

【还没搞定的，我如实说】

· 相机：主线和 CAMSS 都摸到了，但没到能拍照的程度
· 蜂窝：基带（IPA + MPSS）能起来，打电话上网还不行
· 指纹：Goodix 走 TrustZone，主线短期没戏，基本可以放弃
· 续航：还没开深度空闲和系统挂起，比安卓费电
· USB-C 输出到显示器、蓝牙耳机 A2DP：还没验

所以它不是「能当主力机」的状态，是「能当一台能上网、能打字、能听歌的小 Linux 平板」的状态。

【为什么值得折腾：技术上有意思的地方】

1. 双系统怎么共存的
没动安卓的 boot 分区，只借用 recovery_b 当 Linux 入口。安卓正常开机根本不看这个分区，所以 Linux 刷挂了也就是长按电源 20 秒回安卓，风险可控。

2. 高通 ABL 的一个坑
ABL 会把它认为对的 DTB 和 dtbo overlay 叠到你的镜像上，叠到主线 DTB 上直接黑屏卡死。我的解法有点土但有效：镜像头部塞一个厂商 DTB 当「诱饵」让 ABL 满意，内核再用 CONFIG_FUXI_FORCE_BUILTIN_DTB 忽略它、换成编进内核的主线 DTB。

3. Adreno GPU 卡了我很久
GPU 上电要做 ZAP 签名认证，一开始用 /vendor/firmware 里的 zap，TrustZone 直接返回 -22。后来换 /odm/firmware 里小米签名的那份，一次过。同一颗芯片，两个目录，两套签名，就这一个差别。

4. 那些「莫名其妙」的小坑
· 功放 I2C 走的是 GPIO0/1，不是 devicetree 默认的 GPIO56/57（GPIO57 是长焦供电）
· 关机时主线 UFS 驱动忘了放复位线，手机会掉进 EDL 模式
· 根文件系统打包时 setuid 位丢了，导致锁屏密码明明对却一直提示认证失败
· cmdline 里千万别加 console=ttyGS0，主机不读串口的时候写满阻塞，开关机都会卡死几十秒

【怎么复现】

全部材料都开源了，包括内核补丁、设备树、构建脚本、每一版镜像和实机验证日志：

GitHub：github.com/ilovecnxx/xiaomi13-fuxi-linux
最新版：v0.3.0（2026-10-29）

仓库里有：
· 可刷的 boot 镜像（写在 recovery_b）
· 内核配置、diff、新增文件、DTS，照着能自己编
· 每一轮实机验证的时间线和日志
· 一份「都踩过哪些坑」的清单

注意：仓库不含厂商固件和你手机的根文件系统，镜像里那个 801KB 的厂商 DTB 只是给 ABL 看的诱饵，不含可执行代码。

【风险提示】

解锁 BL、刷 recovery_b 都有风险，务必先备份自己的原厂 recovery_b。本文只做记录和分享，刷坏了别找我（笑）。

【下一步】

· 把 120Hz + GPU 这版固化成日常镜像，多跑几天
· 省电：试着开深度空闲和 suspend，看能不能接近安卓的待机
· 相机和基带，慢慢啃
· 亮度、旋转、长按唤醒这些小细节收尾

做到这一步，最想说的一句话是：这台手机的所有硬件，本来都是为安卓准备的；主线内核能把它重新点亮，靠的是一堆人十多年在上游把 Qualcomm 平台的坑一个个填平。我只是把 fuxi 这一块补上而已。

有问题评论区聊，能测的我都会回。

## 四、发布注意事项

1. **Wi-Fi 名称 / IP / 主机名**：`02-wifi.png` 里会有你的网络名和 IP，酷安是公开的，建议裁掉或打码。
2. **序列号**：设置 → 关于里如果显示序列号，记得遮。
3. **别写「日常可用」**：相机、蜂窝、续航都没好，容易被杠；写成「能当小 Linux 平板」更稳。
4. **链接**：酷安正文里 GitHub 链接容易被限流，可以在评论区置顶补充。
5. **标题里带机型 + Linux 更容易被推荐**，纯「Linux 手机」太泛。
6. 如果发视频：开场 3 秒最好是「关机 → 音量上+电源 → 直接进桌面」，比任何文字都说明问题。
