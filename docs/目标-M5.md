# 目标 M5：Linux 脱离电脑独立可用

设定：2026-10-27。前置：M1–M4 已完成（主线内核 7.3 + Ubuntu 26.10，ABL 直接引导，recovery_b 双系统，
屏幕 simpledrm，按键 + 触摸屏，见 `docs/双系统启动说明.md`）。

## 验收标准（全部满足才算完成）

1. 拔掉 USB 线，按住 音量上 + 电源 开机进 Linux；
2. 能看到电量与充电状态，插充电器会真正充电；
3. WiFi：能连路由器上网，能通过 WiFi SSH 进手机；
4. 触摸可用的图形界面（Phosh）：解锁、打开应用、屏幕键盘输入；
5. 普通重启仍回 Android，Android 侧不受影响。

## M5.2 进展与做法（10-27）

- 硬件：引脚/供电与 sm8550-qrd 相同（wlan-en GPIO80、bt-en GPIO81、sw-ctrl GPIO82、PCIe0 perst GPIO94、wake GPIO96），
  DTS 照 QRD 加 `wcn7850-pmu`、`&pcie0`/`wifi@0`、`&uart14`/`bluetooth`。PCIe 链路已通（`0000:01:00.0` 17cb:1107）。
- WiFi 固件全部取自手机自己的 modem 分区 `image/kiwi`（不从外网下载）：`amss20.bin`→`amss.bin`、
  `phy_ucode20.elf`→`m3.bin`（Android cnss 对 Kiwi 就是把它当 M3）、`regdb.bin`；芯片报 `board_id 0xff`，
  小米按机型代号选标定：Xiaomi 13 = M3（电池型号也是 `M3_4500mah_67w`），国行用 `bd_m3.elf`，
  用 `scripts/fuxi-ath12k-board.py` 打包成 `board-2.bin`。实测主线 ath12k 能启动这份固件（WLAN.HMT.1.0.c2-00058.3）。
- 固件在根文件系统里，initramfs 阶段 probe 失败；`fuxi-firmware-devices.service`（`work/rootfs-overlay/`）在根文件系统
  挂好后启动 ADSP、bind 一次 ath12k、必要时 bind 蓝牙 serdev。**不要 unbind/rebind 半初始化的 ath12k：会卡死整机。**
- 蓝牙固件：btqca 要 `qca/hmtbtfw20.tlv` + `qca/hmtnv20.bin`（或按 board id 的 `hmtnv20.bXX`），从 Android
  `/vendor/bt_firmware/image`（bluetooth_b 分区）只读拉取。
- regdb：cfg80211 要签名的 regulatory.db（内核内置 sforshee/wens 公钥），装 Ubuntu 的 wireless-regdb 即可。
- 一条命令跑完部署与验证：`scripts/fuxi-m5-wifi-bt.sh`（镜像 `work/kbuild/abl-fuxi-wifi2.img`）。
- 下一步：用户提供 WiFi 名称/密码后 `nmcli dev wifi connect`；验证 WiFi 下 SSH；然后 M5.3（Phosh）。

## 已在电脑上做完、等上机验证的（10-27 07:40–08:30）

- **UFS 重启进 EDL 的根因与修复**：主线 ufs-qcom 在关机路径（`ufshcd_wl_shutdown` → `ufs_qcom_suspend`，链路关闭）
  里把 UFS 复位线拉住不放；厂商驱动注释说明 TLMM 的 UFS_RESET 寄存器"热复位后不会回到上电默认值"，
  于是启动 ROM 看到 UFS 仍在复位、读不到引导分区 → EDL。补丁：给 ufs-qcom 平台驱动加 `.shutdown`，
  关机后释放复位线（与下游一致）。镜像 `abl-fuxi-wifi3.img` 起已包含；验证几轮重启后可以重新试 HS-G5 补丁。

  （拆分前后 dtb 逐字节一致）。新增 `sm8550-xiaomi-fuxi-full.dts` = 全部功能，镜像 `abl-fuxi-full1.img`（09:22 起 `abl-fuxi-full2.img` = full + 调频温控 + 桌面内核选项）；

- **调频/温控缺失（10-27 09:10 发现）**：主配置里 `CPU_FREQ`、`THERMAL` 都没开——CPU 一直停在引导程序留下的频率，内核也不会过热降频/关机
  （只靠硬件/固件兜底）。`FUXI_PM=1 scripts/fuxi-build-abl.sh pm1`：qcom-cpufreq-hw（EPSS）+ schedutil、TSENS（需 QFPROM）、PMIC 过温（需 IIO）、
  LMh、CPU 冷却、L3 互连调频；上机 `scripts/fuxi-m6-pm.sh`。通过后并入主配置（Phosh 软件渲染很吃 CPU，这项优先）。
- **传感器第一步**：`CONFIG_QCOM_FASTRPC` 进主配置（镜像 `abl-fuxi-wifi6.img`），`scripts/fuxi-sensors.sh`，见 `docs/传感器调研.md`。
- **桌面/日常用的内核选项（10-27 09:15 补进主配置）**：snap 要的 squashfs/loop、FUSE、overlayfs、zram、exFAT/NTFS3/ISO9660、

- **需要用户决定**：振动马达（PM8550B HV haptics）等驱动缺寄存器资料，想从 GitHub 取小米开源内核源码（只作参考，不刷任何东西）。
- **i2c8 引脚错误（10-27 10:10 发现并修复）**：本机 QUP2 SE0（扬声器功放 I2C）走 GPIO0/1（"mirb"），不是 sm8550.dtsi 默认的 GPIO56/57；
  而 GPIO57 是长焦相机 AVDD 开关。audio.dtsi 里改成 mirb 引脚；audio1/audio2/full2 已重编。uart14（GPIO76-79）、i2c hub 2（GPIO20/21）核对无误。
- **相机第一步**：见 `docs/相机调研.md`。测试驱动 `drivers/misc/fuxi-camera-power.c`、`sm8550-xiaomi-fuxi-camera.dtsi`，镜像 `abl-fuxi-camera1.img`，

- **重启后执行链可断点续跑**：`scripts/fuxi-after-reboot.sh`（`--list` 看进度、`--from`/`--only`、进度存 `work/state/after-reboot.done`）。
- **面板 90/120 Hz（10-27 11:50）**：厂商三个 timing 的上电序列只差 3 条命令（0x60、0xbd、0xf2），面板驱动加参数
  `panel_xiaomi_fuxi.refresh=60|90|120`（默认 60，模式时钟跟着变）。镜像 disp4 / desk2 / full3。先 60 Hz 验证通过再试 120。

## 手机回到 Android 后的执行顺序（10-27 更新）

1. `scripts/fuxi-m5-wifi-bt.sh`（默认 wifi6 镜像；后台任务已在等 Android，不用手动跑）

4. `scripts/fuxi-m6-display.sh`（原生显示 + GPU，需要用户看屏幕）
5. `scripts/fuxi-m5-modem.sh`（基带首次启动；需要插 SIM 卡才能看注册/短信）
