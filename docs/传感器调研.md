# 小米 13（fuxi）传感器：调研与计划

更新：2026-10-27。

- SM8550 的传感器（加速度/陀螺、距离、光线、地磁等）挂在 ADSP 的传感器子系统 SSC（sensorspd）上，
  Linux 不直接驱动传感器芯片，而是：
  1. **hexagonrpcd**（Ubuntu 有包，0.4.0）经 FastRPC（`/dev/fastrpc-adsp`，内核 `CONFIG_QCOM_FASTRPC`，已进主配置，
     sm8550.dtsi 里 ADSP 的 fastrpc 节点现成）给 DSP 提供它要读的配置文件；
  2. **libssc + 带 SSC 支持的 iio-sensor-proxy**（postmarketOS/Mobian 的做法）经 QMI 读传感器数据，给桌面提供自动旋转、
     通话时贴脸熄屏（距离）、自动亮度。libssc 有 Ubuntu 包（libssc2 0.4.4、libssc-bin 的 `ssccli` 可直接读加速度/距离/光线/陀螺/地磁）；
     Ubuntu 的 iio-sensor-proxy 3.9 没链接 libssc → 以后在手机上重编一个带 SSC 支持的。
- 文件来源（Android 只读复制，Ubuntu 包默认根目录 `/var/lib/droid-juicer/sensors/`）：
  `acdb` ← `/vendor/etc/acdbdata`、`dsp` ← `/vendor/dsp`、`sensors/config` ← `/vendor/etc/sensors/config`、
  `sensors/registry` ← `/mnt/vendor/persist/sensors/registry/registry`（本机标定）、`sensors/sns_reg.conf` ← `/vendor/etc/sensors/sns_reg_config`。
- 第一步脚本：`scripts/fuxi-sensors.sh`（拉文件 → 进 Ubuntu → 装 hexagonrpcd → 看 sensorspd 是否起来）。镜像 `abl-fuxi-wifi6.img`（主配置 + FastRPC）。
- 第二步：Ubuntu 的 iio-sensor-proxy 3.9 源码已经带 `ssc-support` 选项（drv-ssc-accel/compass/light/proximity），
  只是 Ubuntu 在 `debian/rules` 里把 `ARCHES_QCOM_SSC = arm64` 注释掉了（Debian 默认开）。
  `scripts/fuxi-sensors-proxy.sh`：把同版本源码包（已存在 `work/src/iio-sensor-proxy/`，取自 Ubuntu 镜像）推到手机，
  去掉注释、装 libssc-dev、`dpkg-buildpackage` 重编、安装并 `apt-mark hold`，最后用 `monitor-sensor` 看读数。
