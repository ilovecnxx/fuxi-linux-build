# 手机无线 ADB 方案（重启后自动连接）

更新：2026-10-31 04:20。适用：小米 13 `fuxi`，Android 侧（LineageOS 24，userdebug，已 root）。

## 结论

用 **`persist.adb.tcp.port=5555` + adb 公钥预置 + 主机侧自动重连服务**，做到：
不插 USB、重启后手机开机即监听 5555、电脑自动连上（IP 变了也能找到）。

配套文件：

- 主机脚本：`scripts/fuxi-adb-connect.sh`（mDNS 名字 → 已知地址 → 网段扫描，三级兜底）
- 主机服务：`~/.config/systemd/user/fuxi-adb-watch.service`（常驻，掉线自动重连；已 `enable --now`）

## 手机侧配置（已做，均持久）

```bash
# 1) 让 adbd 开机监听 TCP 5555（persist.* 存 /data/property/persistent_properties，跨重启保留）
adb shell setprop persist.adb.tcp.port 5555
adb shell setprop service.adb.tcp.port 5555      # 本次立即生效
# （等效于 adb tcpip 5555，但属性方式不用重新插 USB）

# 2) 把主机公钥写进授权列表，免"允许调试"弹窗
#    已确认 /data/misc/adb/adb_keys 含 user@user-linux（即本机 ~/.android/adbkey）
```

- `ro.adb.secure=1`：TCP 连接仍需 adb 密钥认证，**不是无鉴权**；公钥已在 `adb_keys` 里，
  所以本机直连免弹窗，别的机器没有私钥连不上。
- **注意**：手机与电脑必须在同一 WiFi 网段（当前手机 `10.10.10.43`，主机 `10.10.10.10`，
  同一 SSID 下）。IP 由 DHCP 分配可能变化，靠 mDNS 名字兜底）。

## 主机侧

```bash
scripts/fuxi-adb-connect.sh          # 连一次（mDNS 名字 → 已知地址 → 扫网段）
scripts/fuxi-adb-connect.sh --wait   # 等手机出现（开机后）
scripts/fuxi-adb-connect.sh --watch  # 常驻，掉线重连（已被 systemd 服务调用）
```

已安装的 systemd 用户服务（linger 已开，登录/重启主机后也在）：

```bash
systemctl --user status fuxi-adb-watch.service
journalctl --user -u fuxi-adb-watch -f
```

## 为什么这样最稳

| 方式 | 重启后自动 | 说明 |
|---|---|---|
| `adb tcpip 5555` | ❌ | 只在本次 adbd 生命周期有效，重启丢失 |
| 系统设置里的无线调试（随机端口/配对） | ⚠️ | 端口每次随机、要重新配对；`_adb-tls-connect` 服务随 android adb wifi 起 |
| **`persist.adb.tcp.port=5555`** | ✅ | 属性持久化，开机 init 即让 adbd 监听 5555（经典行为） |
| mDNS 名字连接 | ✅ | `_adb._tcp` 服务带 IP+端口，IP 变化不影响 |

## 待办 / 风险

- **重启验证**：属性已在持久存储，按 Android 经典行为应开机即监听 5555；但"重启后自动连"
  需要真重启一次才算实测（重启前需用户同意——项目约定自主重启需明确许可）。
- 安全：5555 明文 TCP 在局域网；靠 `ro.adb.secure=1` + 密钥认证保护。若担心可改端口或
  只在需要时开；不建议在不可信网络下开启。
- 若某次系统更新把 `persist.adb.tcp.port` 的支持去掉（极少见），退回 mDNS 名字连接仍然可用。
